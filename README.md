Mở Terminal (hoặc Command Prompt) tại thư mục do_an_odoo.

Gõ lệnh: docker-compose up -d. Chờ vài phút để Docker tải Odoo và Postgres về máy.

Mở trình duyệt web, truy cập: http://localhost:8069.

Màn hình tạo Database xuất hiện. Bạn nhập thông tin tùy ý (Ví dụ: Email: admin, Password: admin) và bấm Create database.

Đăng nhập vào hệ thống, vào menu Settings (Cài đặt), cuộn xuống dưới cùng và bấm Activate the developer mode.

Trở lại menu Apps (Ứng dụng), bấm Update Apps List trên thanh công cụ.

Xóa bộ lọc "Apps" ở ô tìm kiếm, gõ Tech Startup HR Demo và bấm Install.
